## 2. Partial rows by what closing them takes

Method. `$S/rank/classify2.py` takes each proof's gap text (from "Missing", "not covered", "Not yet", else the prose after the citations), drops file paths and the boilerplate "before the merge this row was model only" clause, splits it into clauses at semicolons and sentence ends, and classes each clause by patterns in the order X, W, T, V, B. A row is X if any clause is X (it then counts zero for ordinary slices), T only if every classed clause is T, the single other class if all other clauses agree, and M if two non-test classes appear. R marks a row whose text only points at another row ("see the action", "same as …"): it rises with that row. 119 partial rows were classed by hand (`$S/rank/overrides.json`): every row the patterns could not place (96), every row a pattern pass called T (66 in the first pass, 53 in the second; 21 moved out of T, 5 moved in after comparing the two passes with `cls_auto.json`). Where a clause states that native behaviour differs from the webview's in existing code (a fix rather than a missing feature), it is counted as B; B is therefore "behaviour or feature not built", broader than a backend call.

## 5. Ranked slices

Rows to parity are judged: a row is counted only when every clause of its gap is something the slice does. Rows named is the list in `$S/rank/slices.json`, counted. Sizes are judged. Rows per pass is the judged count divided by passes (one to two passes counts as 1.5, two to three as 2.5). Basis says what the judged count rests on: a row's own text read, a shared clause read, a design or draft, or an estimate over empty rows that no clause bounds (those are the least certain and should not be ranked alike with the others). The 32 ranked slices name 277 rows (no row in two slices, checked by `slices_def.py`; the 25 rows of the placeholder slice 33 are not counted) and are judged to raise about 186, 49 of them in the three harvest batches. In flight and left out: the seven rows of wiring batch 1's brief; the 25 new settings rows and the pending test files (sibling reader).
