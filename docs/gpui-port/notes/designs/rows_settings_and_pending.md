- A checkbox's inline control (`Caret blinking (ms): [500]`) is a separate option in the native spec; the webview disables it while the checkbox is off (`kit.tsx:30-31`). - Tests that are NOT page proofs: `settings_view::dialog::tests::*` and `settings_view::controls::tests::*` draw synthetic specs built inside the tests (`dialog.rs:1216-1230`, `controls.rs:955-983`, `:1248-1274`) and are not cited; `settings_model::staging::tests::*`, `settings_model::builtin_pages::tests::*` and `settings_model::inspections_model::tests::*` are model only and are cited only on the three pages with nothing drawn, labelled "(model)", to show the page is registered.
