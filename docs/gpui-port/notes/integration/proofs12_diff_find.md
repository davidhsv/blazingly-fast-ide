## Hunk H1 (only `proofs12_diff_soft_wraps.rs` depends on it)

In `app-gpui/src/vcs_diff/view.rs`, `impl DiffView`, next to `pub fn options`:

```rust
    /// Whether the panes wrap long lines.
    pub fn soft_wraps(&self) -> bool {
        self.options.soft_wrap.unwrap_or(false)
    }
```

That body is today's behaviour: an override only. The feature itself would resolve `None` against `editor.softWrap` and `editor.general.softWrapFiles` (`editor_model::editor_prefs::matches_file_patterns`) for the diff's file, through the settings the viewer already follows (`follow_editor_settings`, `listen_to_editor_settings`). It would also make the panes wrap. With this body the three soft-wrap tests fail at their editor-following assertions, or earlier at the missing "Use Soft Wraps" menu item.

## Expected to fail, with the missing behaviour and where it goes

- **F1. A revision-to-revision diff has no Jump to Source** (diffToolbar 9, 22, 23, 24). `DiffDialog::loaded` sets `has_source` from `side_file`, which is `None` for `DiffSide::Rev`. `Workbench::jump_to_diff_source` (`workbench/diff_window.rs:507`) returns early when neither side is a file. The webview probes the working file (`fsProbe(path)`) and maps a revision line to the working copy through a second diff. Fix: in `diff_window.rs`, after loading, probe `data.path` (`ide_host::ops::bytes::fs_probe`) and call `set_has_source(true)` when the file exists. For a jump from a revision side, load the working text, map the line to the newest revision side first (`DiffView::map_line` for the left side), then through a diff of that revision against the working text, and open that line.
- **F2. Soft wraps in the diff viewer** (diffToolbar 11–13). `DiffViewOptions::soft_wrap` is parsed and stored but read nowhere. No "Use Soft Wraps" item exists in `toolbar_view::settings_menu`, there is no `DiffCommand` for it, and the panes do not wrap. Fix: `DiffCommand::ToggleSoftWrap` and a checked "Use Soft Wraps" item in `settings_menu` (storing `Some(!current)`); resolve `None` against the editor's Soft-wrap files for the file (H1's accessor then returns the resolved value); wrap in the pane layout of `vcs_diff/view.rs`, keeping the caret and the entity.
- **F3. The non-modal commit interface shows diffs in editor tabs** (diffDialog 8; diffToolbar 15 and 17 have no surface). `Workbench::show_diff` passes a literal `false` for `non_modal` to `show_diff_files`, and shows `ShownDiffs::Tabs` in the front window anyway, while `vcs.commit.nonModal` defaults to `true`. So with default settings, native Show Diff from the Commit tool window opens a front window where the webview opens an editor tab. Fix: pass `settings::effective(&self.label, cx).vcs.commit.non_modal`, as `log_window.rs` does, and add a diff editor tab kind (`EditorInput.kind == "diff"`, which the test looks for) that hosts a `DiffView` with the toolbar and the Maximize Editor / Restore Size control. Diff tabs are the missing surface.
- **F4. Moved code in the viewer** (movedCode 11, 13). Only the counter knows about moves (`DiffSummary::moves`). Nothing draws moved lines, move links or move edits. Fix in `vcs_diff/view.rs` rendering, with the selectors the tests use: `diff-moved-left-{i}` (moved lines marked), `diff-moved-to-{i}` (link on the left at the block's first line: "Go to moved code at line N", which puts the caret at `MovedBlock::line_b` on the right), `diff-moved-from-{i}` (link on the right back to `line_a`), `diff-moved-edited-{i}` (the "(edited)" label of a move with `changes`), and `diff-move-edit-left-{i}` / `diff-move-edit-right-{i}` (the word edits, omitted in Highlight lines mode, and everything omitted in Do not highlight).
- **F5. The diff window is not resizable** (diffDialog 5). `diff_window_layer` uses fixed `MARGIN_X` / `MARGIN_Y`. Fix: a grip with the debug selector `diff-window-resize` at the bottom-right of the window in `diff_window_layer`; a size kept in `UiStorage` (for example `openidea.vcs.diffDialogSize.v1`, `{w,h}`) and clamped to a minimum; the window centred at that size when it opens.
- **F6. The diff window does not own the close shortcut** (diffDialog 7). `DiffDialog::key` handles plain Escape only, so ⌘W (Ctrl+F4) runs `editor.closeTab` on the tab behind it. Fix: in `DiffDialog::key`, also close on the keystrokes bound to `editor.closeTab` / `toolwindow.closeContent` (`KeymapState::bindings_for`) and claim them.
- **F7. The Find in Files popup is not resizable** (findPopup 21). The root is fixed at `WIDTH` (820), with fixed `RESULTS_HEIGHT` and `PREVIEW_HEIGHT`. `resiz` occurs nowhere in `find/popup_view.rs`, and the root has no debug selector. A native resizable popup needs:
  - a `size: Option<Size<Pixels>>` on `FindPopup`, read in `FindPopup::new` from `UiStorage` key `openidea.search.findPopupSize.v1` (`{"w":…,"h":…}`, the webview's key);
  - the root drawn at that size, with `debug_selector("find-popup")`, the results and preview taking the height that is left (flex instead of the fixed heights);
  - a grip element `find-popup-resize` at the bottom-right whose left mouse-down starts a drag, followed by window-level mouse move and up while dragging, clamped to a minimum size, with the size stored on mouse-up;
  - `Workbench::popup_body` (`workbench/popup_placement.rs`) leaving the popup's own size alone.
- The ⌘↓ test returns early off macOS.
