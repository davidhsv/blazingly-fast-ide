## Most likely to fail on first run

- `proofs15_reload_all`: it assumes the backend's repository read needs no executor timer. If the read waits on a GPUI timer, the second `work_without_the_clock` times out. If the watcher's `VcsChanged` refresh ran without the timer, the first check (nothing reads on its own) fails.
- `proofs15_terminal::close_session_asks…`: it waits for `view.id()` to be set before reading it. Also, `set -m` in the non-interactive plain shell has to give `sleep` the terminal's foreground process group (bash in POSIX mode on macOS, dash on Linux). If it does not, the wait for `is_busy` times out.
- `proofs15_reformat`: the fake server must answer `textDocument/codeAction` for the organize-imports request, and the editor's lightbulb may send `codeAction` requests of its own (only the first one with `only: ["source.organizeImports"]` is checked).
- `proofs15_folding`: a click at the old chevron point now lands in the text; the asserted caret line 1 assumes that point is inside line 1's row.
- `proofs15_paste_history`: the expected `chosen()` order for the secondary-modifier and Shift clicks assumes list order and that `select_row` anchors the range at the previous click.
- `proofs15_github_refresh`: the rewritten check is also made required (`isRequired: true`), because `ci_summary` (`github/details.rs:268`) keeps "All required checks have passed" for a failed non-required check; the test then waits for "Checks failed".
- `proofs15_plugins`: only `load_all` reads the `.uninstall` records (`plugins/mod.rs:511`), and the reload does not call it, so the `{}` record is not parsed; it assumes `host.list` does not drop a plugin that has one.

## Behaviours found that differ from the webview

- Fold by default is not applied when a file opens.
- Implement, Generate and Override do not reformat the lines the server inserted.
- Reformat File… always offers Optimize imports; the webview disables it when a plugin's formatter formats the file (`contributedAt(view.state, CONTRIBUTED_FORMAT, 0)`).
- Paste from History hard-codes Enter, Delete and Backspace instead of following the keymap's bindings for its actions.
- Refresh Pull Request does not reload a loaded timeline or review threads.
- `run.updatableRunning` ignores debug sessions (and, as a hypothesis to confirm, `run.updateApplication` has no handler).
