## 5. Native fix (`app-gpui/src/workbench/database.rs`, about 30 lines)

With only a cell being edited, native kept `dbTableEditorChanges` off, so Revert and Submit were unavailable. The webview turns it on (`tableEditorFocus.ts:52`). The fix:

- **`sync_database_context`** counts an open cell field as a change, for both the table editor and the console's result grid.
- **The grids are observed**, so the context updates when a cell's field opens or closes.
- **The cell's own field counts as focus** in the grid (new `cell_field_focused`). A field just opened is not drawn yet, so `contains_focused` misses it until the next frame. This kept the existing `submit_revert_and_go_to_column_reach_a_focused_console_result` passing.

Hypothesis: the table editor half of the fix works like the result grid's, but no test drives it. A copy of `edit_a_result_cell` on a table opened with Edit Data would confirm it.
