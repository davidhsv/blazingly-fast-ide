## Left out, and why

- **Shared undo between a tab and the preview:** needs a history per document, which `Editor` does not have.
- **Case 7, other kinds:** `library` and `archive` need fixtures I did not build. `binary` files are skipped by Find in Files, so no result reaches the preview. A 5 MB `large` file opens writable natively.
- **Show Usages popup's preview pane:** it stays a plain window of lines, because changing it breaks the popup's own tests. Its rows are coloured.
- **Labels and folding:** the accessibility labels are not built, and the preview shows fold chevrons where the webview shows none.
- **Shortcuts in the preview:** all IDE shortcuts are blocked while the preview has the keyboard; the webview blocks only text-editing ones.
- **Usages pane colours:** matches use the editor's search colours, not the webview's accent colour.
- **Empty lines:** an empty current line gets no tint.
- **Stale row colours:** a row keeps old colours when only its surrounding context changed (for example a comment opened above it).
