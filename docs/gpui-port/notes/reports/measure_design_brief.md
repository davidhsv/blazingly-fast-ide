## Why

The repository is an IDE: a Rust backend (`crates/`), a Tauri 2 shell (`src-tauri/`) with a React/TypeScript webview UI (`src/`), and a native rewrite of that UI on GPUI (`app-gpui/`, its own Cargo workspace, using the same backend crates). The rewrite is far from complete (about 1,170 of 3,782 inventory rows at parity). The owner wants to know now, before weeks more of work, whether the native UI pays off in memory and CPU: a preliminary measurement of release builds of both apps over these scenarios: cold start; open a large project (`/Users/davidvieira/code/Allocadia`, read-only); open 10 files and scroll each; Find in Files; the Git log; switch Blaze → Deep → back (the fork's two modes: Blaze runs without language servers, Deep with them: find them in `src/` and `app-gpui/src`); 10 minutes idle.
