Native `workbench/branches.rs` passes `false`: its rename dialog has no such checkbox (listed in part 6).
- `ide_host::ops::vcs::vcs_stash_push` gained `paths: Option<Vec<PathBuf>>` (f154bf8c8 "feat(vcs): stash only the selected files (#3314)"; the webview passes `null` without a file selection). Native `workbench/vcs_operations.rs` passes `None` (stash everything, as before).
